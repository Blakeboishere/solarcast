# SolarCast — Solar Generation Prediction UI Prototype

A responsive, front-end-only dashboard prototype built with HTML, CSS, and vanilla JavaScript.

## Run it
Open `index.html` in a browser. No build tools or package installation required.

## Included
- Solar generation dashboard with predicted yield, peak power, sunlight hours, and model accuracy
- Canvas-based hourly generation chart with confidence band
- Weather insight card and AI recommendation panel
- Site selector with three sample solar sites
- Expandable hourly breakdown
- Modal dialogs, toast notifications, and mobile sidebar
- Responsive desktop/tablet/mobile layout

## Important
All energy and weather values are illustrative demo data. The prototype does not connect to a weather API, a database, or a trained prediction model. Replace the sample data in `script.js` and connect your forecasting backend when you're ready.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive styling
- `script.js` — chart rendering and UI interactions
